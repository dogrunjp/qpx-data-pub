# Rice mitochondrial complex I: GPML generated with PathLift

[Os_mitochondrial_complex_I_by_PathLift.gpml](Os_mitochondrial_complex_I_by_PathLift.gpml) is a pathway diagram for *Oryza sativa*, generated by lifting over the [Arabidopsis mitochondrial complex I GPML](<../../Arabidopsis thaliana/mitochondrial_complex_I/At_mitochondrial_complex_I.gpml>) using [PathLift](https://github.com/dogrunjp/PathLift).

**Only GPML drawing data are included; no transcriptome, proteome, or expression tables are provided.**

## How it was created

PathLift replaces or expands source `GeneProduct` nodes with candidate genes in the target species. For this dataset, the source was *Arabidopsis thaliana* and the target was *Oryza sativa* Japonica Group (taxid `39947`), using the AGIS nuclear reference recorded in the GPML run-context comment.

Mapped nodes use `Xref Database="assembly"` and target GFF gene IDs, such as `gene-LOC4344095` (displayed as `LOC4344095 (Os07g0645400)`, corresponding to source CI51). GPML comments retain the original Arabidopsis labels, candidate gene/transcript IDs, and mapping routes. Multiple candidates can appear as separate nodes.

## Contents and mapping notes

| Item | Value |
| --- | --- |
| GPML format | 2013a |
| Organism attribute | `Oryza sativa` |
| Version attribute | `20250916` (as recorded in this GPML) |
| Data nodes | 85: 73 gene products, 1 protein, 5 metabolites, and 6 module/domain headings |
| Other elements | 3 interactions, 5 shapes, and 8 groups |

The diagram retains the N, Q, PP, and PD modules, CA domain, and candidate plant-specific subunit heading, together with NADH, NAD+, and H+ nodes.

- Of the 73 gene-product nodes, 61 have candidate mappings representing 47 distinct target gene IDs; 12 remain unmapped. These are diagram counts, not confirmed rice complex I subunit counts.
- The reference covers nuclear genes. Unmapped organellar nodes retain Arabidopsis cross-references. `AT1G76200` also remains unmapped because no BLASTp hit passed the run's filters.
- According to the run-context comment, the nad2 and nad9 candidates are nuclear Helixer predictions, not rice organellar annotations.
- The source `Protein` node (`AT2G42310`, UniProt `A0A178VYI3`) is preserved because PathLift transforms `GeneProduct` nodes only.

## Viewing with QPX

Copy the GPML into the [QPX](https://github.com/bonohu/qpx) project's `gpml/` directory, run the following cell in `qpx.ipynb`, and select `Os_mitochondrial_complex_I_by_PathLift.gpml`.

```python
import qpx_widgets

visualizer = qpx_widgets.GpmlD3Visualizer(
    expression_data_path=[],
    expression_columns_index=[],
)
visualizer.show()
```

The empty lists configure diagram viewing without expression tables, following the [QPX implementation](https://github.com/bonohu/qpx/blob/main/qpx_widgets/qpx_widgets/visualizers.py). Runtime rendering has not been verified. For future omics integration, match table identifiers to the target GFF gene IDs and account for nodes retaining source identifiers.
